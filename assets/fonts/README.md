# Fonts

Inter font files are **already included** in this directory — no manual download needed.

Files:
- Inter-Regular.ttf    (weight 400)
- Inter-Medium.ttf     (weight 500)
- Inter-SemiBold.ttf   (weight 600)
- Inter-Bold.ttf       (weight 700)
- InterVariable.ttf    (variable font, all weights — not currently used)

Inter is free and open-source, licensed under the SIL Open Font License 1.1.
Source: https://rsms.me/inter/
